# visualizador-perfil-github

O JavaScript está organizado em módulos ES6: `index.js` inicializa a aplicação, `search-controller.js` gerencia a busca, `services/github-api.js` consulta a API do GitHub e `ui/profile-view.js` renderiza os resultados.

Como a aplicação usa módulos ES6, abra `index.html` por meio de um servidor HTTP local (por exemplo, com a extensão Live Server do VS Code).
